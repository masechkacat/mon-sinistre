# PRD: Экран синистра как досье

**Дата**: 2026-10-17
**Статус**: approved <!-- draft → approved → done; в реализацию берётся только approved -->

## Цель

Пострадавший открывает синистр и видит один лист досье, а не список карточек:
где стоит дело, сколько осталось до декларации, что делать сейчас и что уже
сделано. Экран собран по принятому макету `docs/design/sinistre.html`
(тур 16b): текущий код `/sinistres/[id]` и `/dossier` отражает дизайн до него.
Это контрольная фаза харнеса (`docs/plan/harness-v2.md`, фаза 5): одна
UI-фаза под новыми правилами, с замером против базы.

## Пользовательские сценарии

- Пострадавший открывает `/sinistres/[id]` → в шапке видит событие, штемпель
  статуса, хронологию ключевых дат и остаток дней до декларации одним
  бейджем; ниже — закладку «Étape en cours» с прогрессом «N étapes faites sur
  M» и план полосами на листе.
- Пострадавший отмечает шаг-действие сделанным → шаг уходит в строку «Fait»
  внизу листа, закладка показывает следующий шаг, прогресс растёт на один.
- Пострадавший на шаге «Déclarer le sinistre à votre assureur» вводит дату
  декларации прямо в полосе шага → полоса сворачивается в «Fait le …», даты
  шагов после декларации появляются; дату можно стереть там же.
- Гость открывает `/dossier` с параметрами → видит тот же лист в режиме
  чтения: без отметок, без формы даты, контейнеры с текстом «что собрать».
- Пострадавший открывает экран с телефона (320 px) → хронология в шапке
  вертикальная, полосы в одну колонку, главное действие видно без прокрутки
  по горизонтали.

## В скоупе

- Шапка: событие и коммуна, штемпель статуса синистра, хронология из
  четырёх точек (événement, arrêté, déclaration, indemnisation) с датой или
  словом «à venir» / «attendu», бейдж остатка дней в форме `hero`.
- Закладка «Étape en cours»: имя ближайшего шага, прогресс «N étapes faites
  sur M» текстом и полосой.
- План как полосы одного листа: шаги-действия с датой и отметкой «fait»;
  контейнеры (photos, factures, biens) — полосы с текстом «что собрать» и без
  действий, пока инвентаря нет; шаг декларации — единственная обведённая полоса
  с формой даты внутри; строка «Fait» внизу со сделанными шагами и возможностью
  отменить отметку.
- Бейджи в строках плана убираются; форма `row` бейджа удаляется из кода.
- Оба экрана, `/sinistres/[id]` и `/dossier`, на общих компонентах плана;
  `/dossier` — режим чтения.
- Обе темы, 320 px и 200 %, клавиатура, axe.

## Не в скоупе

- Изменения API и схемы: инвентарь, файлы, поля страховщика (карточка «MAIF,
  contrat n°»), дата публикации arrêté в ответе `GET /sinistres/:id`.
- Иконки; точка «expertise» хронологии (шага в шаблоне нет); слияние
  `/sinistres/nouveau` с `/dossier`; мобильный макет (выводится из правил
  design-system).
- Генерация письма декларации и état estimatif (ТЗ § 3.4 — отдельная фича).

## Ограничения

- Макет — `docs/design/sinistre.html`, десктоп; значения цветов — только
  токены design-system, новых токенов фаза не заводит.
- Расчётные даты по-прежнему со ссылкой на источник (`SourceNote`) и словом
  «ориентировочно» — приложение не даёт юридических консультаций (ТЗ § 7).
- Остаток дней, статусы шагов, пороги — из API и contracts, клиент их не
  считает (`docs/research/design-system.md`).

## Критерии готовности

- [ ] На `/sinistres/[id]` и `/dossier` шапка содержит штемпель со словом
      статуса, четыре точки хронологии с датой или словом, один бейдж `hero`;
      бейджей в строках плана нет.
- [ ] Закладка показывает имя ближайшего несделанного шага и «N étapes faites
      sur M», где N — число шагов `FAIT`, M — число шагов плана.
- [ ] Отметка «fait» переносит шаг в строку «Fait», прогресс растёт на один;
      «Annuler ce choix» возвращает шаг в план.
- [ ] Контейнер не имеет кнопок отметки ни в одном режиме; его полоса содержит
      текст из `fr.dossier.conteneur`.
- [ ] Дата декларации вводится и стирается в полосе шага декларации; после
      ввода полоса показывает «Fait le <дата>».
- [ ] `npm run test:web` зелёный, включая `tests/a11y` (axe, reflow 320 px и
      200 %, контролы) и обновлённые снимки; `npm run test:e2e` зелёный.
- [ ] `/ui-review` чисто на обоих экранах в обеих темах.
