# PRD: Фундамент клиента и главная страница

**Дата**: 2026-08-02
**Статус**: draft <!-- draft → approved → done; в реализацию берётся только approved -->

## Цель

Житель, впервые попавший на сайт, за один экран понимает, чем сервис ему
полезен: он узнает о публикации arrêté catastrophe naturelle в день публикации и
не пропустит срок декларации. Вместе с этой страницей у клиента появляется общий
каркас — компонентная база, локализация, обращение к API и проверка доступности,
— на который встают все последующие экраны.

Это фича-предпосылка: до неё в `apps/web` нет ни компонентной базы, ни
механизма локализации, ни слоя работы с API, ни проверки доступности, а любая
форма продукта обязана всё это иметь.

## Пользовательские сценарии

- Человек, впервые открывший сайт → понимает, что такое arrêté CatNat, что
  делает сервис и чего он не делает, без специальных знаний.
- Человек, пользующийся только клавиатурой → проходит всю страницу, всегда видит
  фокус.
- Человек со скринридером → получает осмысленную структуру заголовков и может
  сразу перейти к основному содержимому.
- Человек, увеличивший шрифт до 200 % → читает страницу без горизонтальной
  прокрутки.
- Человек с телефона → читает страницу без горизонтальной прокрутки.
- Пользователь, у которого запрос к API не удался → видит французское сообщение
  об ошибке, а не пустой экран.

## В скоупе

- Компонентная база интерфейса и общий каркас страницы: шапка, подвал,
  переход к основному содержимому, заголовки, светлая и тёмная темы.
- Механизм локализации: все пользовательские строки во французских файлах
  локализации, форматирование дат по локали `fr-FR`.
- Единый способ обращения к API: базовый адрес, обработка ошибки запроса и её
  показ пользователю.
- Главная страница: что такое catastrophe naturelle и arrêté простыми словами,
  что делает сервис, чего он не делает (не даёт юридических консультаций и не
  общается со страховщиком), что произойдёт дальше.
- Страницы «не найдено» и «ошибка сервера» на французском.
- Юридические страницы, обязательные до сбора любых данных: mentions légales и
  politique de confidentialité, ссылки на них в подвале. Содержание текстов
  даёт владелец продукта (TBD), фича обеспечивает страницы и ссылки.
- Проверка доступности как часть процесса: автоматическая проверка (axe) на
  каждой странице и ручная проверка с клавиатуры.

## Не в скоупе

- Форма подписки veille и любые другие формы — принадлежат своим фичам.
- Аккаунт, вход, личный кабинет.
- Déclaration d'accessibilité — публикуется по результатам аудита готового
  продукта (ТЗ § 7), а не по одной странице.
- Дизайн-система сверх компонентной базы: иллюстрации, бренд, анимации.
- Многоязычность.
- Аналитика посещений и любые сторонние скрипты трекинга.
- Тексты о том, как действовать после катастрофы (план действий), — принадлежат
  фиче синистра.

## Ограничения

- Доступность WCAG 2.1 AA / RGAA 4.1.2 — жёсткое требование ТЗ § 7: аудитория
  в остром стрессе, значительная доля пожилых.
- Язык интерфейса — французский, `<html lang="fr">`; все строки в файлах
  локализации, в contracts текстов UI нет.
- Компонентная база — shadcn/ui на Base UI, как зафиксировано в
  `apps/web/CLAUDE.md`; отдельных библиотек примитивов сверх этого не
  подключать.
- Единый способ обращения к API — TanStack Query (`apps/web/CLAUDE.md`):
  собственного слоя на `fetch` + `useState`/`useEffect` фича не заводит.
- Расчётные даты и справочные сведения всегда подаются со ссылкой на источник и
  предложением сверить со страховщиком — приложение не даёт юридических
  консультаций.
- Изменение UI считается завершённым только после визуальной проверки в браузере
  и дизайн-ревью (правило `apps/web/CLAUDE.md`).

## Критерии готовности

- [ ] Главная страница объясняет, что такое arrêté CatNat, что делает сервис и
      чего он не делает; текст читается без специальных знаний.
- [ ] Главная и юридические страницы проходят axe без ошибок.
- [ ] Все страницы полностью проходимы с клавиатуры, фокус виден на каждом
      интерактивном элементе.
- [ ] При масштабе 200 % и на ширине экрана 320 px нет горизонтальной прокрутки.
- [ ] Контраст текста не ниже 4.5:1 (3:1 для крупного текста и элементов
      управления) в обеих цветовых темах.
- [ ] Все пользовательские строки берутся из файлов локализации; ни одной
      французской строки в компонентах.
- [ ] Дата, выведенная на странице, отформатирована по локали `fr-FR`.
- [ ] Неудачный запрос к API показывает пользователю французское сообщение об
      ошибке, и оно объявляется скринридером.
- [ ] Несуществующий адрес открывает страницу «не найдено» на французском, а не
      системную страницу фреймворка.
- [ ] В подвале есть работающие ссылки на mentions légales и politique de
      confidentialité.
- [ ] Анимации отключаются при `prefers-reduced-motion`.
