# UI-ревью

Проверь изменённый UI `@mon-sinistre/web`: $ARGUMENTS. Если аргументов нет —
область берётся из `git diff origin/main...HEAD -- apps/web/src`.

Правила ты не запоминаешь, а читаешь перед прогоном: `apps/web/CLAUDE.md`
(«Правила проекта» — доступность, французский, слой API) и
`docs/research/design-system.md` (роли цветов, поверхность papier, шрифты,
бейдж дедлайна, типографическая шкала). Этот скилл задаёт порядок проверки,
не её содержание.

## 1. Детерминированное — тестами, не глазами

`npm run test:web -- tests/a11y`: axe, контраст ролей, цветовые литералы в
исходниках, шрифты, reflow, reduced-motion, литералы вне `fr.ts`. Красный
тест — находка номер один; дальше не идти, пока не зелёный. Что тест
проверил, глазами не перепроверять.

## 2. Вживую — Playwright MCP

Для каждой затронутой страницы, на ширине 320 px и на десктопе, в светлой и
тёмной теме. Тёмная — эмуляцией `prefers-color-scheme: dark`; если инструмент
её не даёт, напиши это в отчёте, а не пропускай молча.

- **Только клавиатура.** Tab от skip-link до главного действия: порядок
  логичен, фокус виден на каждом шаге, ничего не пропущено и ни во что не
  упёрлось. Модалка: trap, `Escape`, возврат фокуса.
- **Снапшот доступности** (`browser_snapshot`), не скриншот: у каждого
  интерактивного элемента есть имя; статус шага и ошибка поля читаются
  текстом; live-регион существует до изменения и меняет только текст.
- **Масштаб 200 %**: ничего не обрезано, горизонтальной прокрутки нет.
- **Главное действие экрана** — одно, кнопка `touch`, не в киновари
  (киноварь — дедлайн и ошибка, см. research).
- **Тёмная тема**: содержимое на поверхности `papier` сохраняет чернила листа,
  а то, что лежит на фоне, — роли «sur fond»; ничто не выглядит инверсией.
- **Тексты** — для человека, который столкнулся с процедурой впервые и в
  стрессе: термин объяснён при первом употреблении, расчётная дата подана как
  ориентировочная со ссылкой на источник, ошибка говорит, что делать дальше.

## 3. Отчёт

Только находки, каждая одной-двумя строками: страница и тема, `файл:строка`,
правило и где оно записано (раздел `CLAUDE.md` или research), что увидит
пользователь, минимальная правка. Скриншот — только к находке, не «для
протокола». Без похвалы и без пересказа того, что прошло.

Итог одной строкой: `UI-ревью: N находок` или `UI-ревью: чисто`. По
`apps/web/CLAUDE.md` задача завершена только при «чисто».
