# Ревью по запросу

Ревьюер получает точно собранный контекст, не историю сессии: диапазон,
что сделано, что требовалось. Внутри итерации Ralph этот скилл не
запускается (`.claude/ralph.md` § 5): там работают `dry-reviewer` и
`constraints-reviewer`, а общее ревью делается один раз по PR всей фазы.

## Как запустить

1. Диапазон:

   ```bash
   BASE_SHA=$(git merge-base origin/main HEAD)
   HEAD_SHA=$(git rev-parse HEAD)
   ```

2. Субагент `general-purpose` с промптом из [code-reviewer.md](code-reviewer.md),
   плейсхолдеры заполнены.

3. По отчёту: Critical и Important — исправить до мержа; Minor — исправить
   или назвать, почему нет; «Отложено» — оставить в PR комментарием.
   Ревьюер неправ — ответить кодом или тестом, не согласием.
