# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Контекст всего монорепозитория — в корневом `../../CLAUDE.md`. Здесь — специфика `@jalons/web`.

## Стек

Next.js 16 (App Router, `src/app/`), React 19, Tailwind CSS 4 (через PostCSS, без tailwind.config). По ТЗ компонентная база — **shadcn/ui**; компоненты со сложным управлением фокусом (прежде всего выбор даты) — **React Aria Components**.

## Команды (из apps/web)

```bash
npm run dev    # http://localhost:3000
npm run build
npm run lint
```

API ожидается на http://localhost:3001. Тестов в этом пакете нет — доменная логика тестируется в API.

## Особенности сборки

- `@jalons/contracts` подключён через `transpilePackages`: Next компилирует его исходники сам, собирать contracts перед запуском web не нужно.
- Включён `typedRoutes` — ссылки на несуществующие маршруты не пройдут типизацию.

## Актуализация документации

При изменении архитектуры клиента обновлять этот файл в том же коммите: подключение shadcn/ui и React Aria Components (сейчас они запланированы по ТЗ, но ещё не установлены), появление слоя работы с API, механизма локализации, тестов. Изменения, затрагивающие весь монорепозиторий, — в корневом `../../CLAUDE.md`.

## Правила проекта

- **Язык интерфейса — французский** (`<html lang="fr">`). Все пользовательские строки — в файлах локализации, не в компонентах; даты форматируются по локали `fr-FR`. Тексты рассчитаны на пользователя, проходящего процедуру впервые: административные сокращения (MDPH, CDAPH, AEEH…) при первом употреблении расшифровываются.
- **Доступность — обязательное требование** (раздел 9 ТЗ, ориентир WCAG 2.1 AA / RGAA 4.1.2). Ключевое:
  - всё доступно с клавиатуры, видимый фокус не отключается никогда;
  - статус шага передаётся текстом, а не только цветом;
  - поля форм программно связаны с подписями, ошибки объявляются скринридером;
  - динамические изменения объявляются через `role="status"` / `role="alert"`;
  - модальные окна: focus trap, `Escape`, возврат фокуса;
  - работоспособность при масштабе 200%, поддержка `prefers-reduced-motion`, обе цветовые темы с контрастом 4.5:1 (3:1 для крупного текста и элементов UI).
  - В layout уже есть skip-link «Aller au contenu principal» на `#contenu` — сохранять этот паттерн на новых страницах.
- Статусы досье и шагов, константы порогов — из `@jalons/contracts`; отображаемые подписи к enum-значениям живут в локализации клиента, в contracts их нет.
- **Любое изменение UI завершено только после визуальной проверки.** Обязательно: (1) запустить приложение и проверить изменение вживую в браузере (Playwright MCP: снапшот/скриншот затронутых страниц, взаимодействие с изменёнными элементами); (2) прогнать проверку через скилл **ui-ux-pro-max** (дизайн-ревью изменённого UI). Пока оба пункта не выполнены, задача не считается завершённой — «код написан и компилируется» недостаточно.
- Расчётные даты всегда подаются как ориентировочные с предложением уточнить в своей MDPH — приложение не даёт юридических консультаций.
