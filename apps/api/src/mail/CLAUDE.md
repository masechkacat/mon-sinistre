# CLAUDE.md — `src/mail`

**Единственная точка выхода письма из API — `MailService.send()`**, обязательна
для всех фич; там же будут лимиты частоты. Решения — `docs/research/emails.md`
(снапшот на 03.08.2026).

Промис вернулся — транспорт принял письмо, иначе `MailCompositionError` или
`MailDeliveryError`; «тихого успеха» не бывает, проверять в ответе нечего.

## Сборка письма

- **Ссылка прекращения писем — обязательный вход** (`unsubscribePath`): тип не
  даёт её опустить, и та же ссылка уходит в
  `List-Unsubscribe`/`List-Unsubscribe-Post`.
- **Каркас получает свои два значения объектом опций** (`MailComposerOptions`:
  `baseUrl`, `senderEmail`), как и транспорты — за конфигурацией лезет только
  `useFactory`. Ни один класс модуля не знает `ConfigService`.
- **Абсолютный адрес собирает только каркас**: блок `link` несёт путь, базу
  каркас берёт из `FRONTEND_URL`; второй склейки базы в фичах не заводить. Путь
  принимается, только если разобранный адрес остался на origin базы — поэтому
  `FRONTEND_URL` не может нести путевой префикс.
- Тема и адрес получателя — одна строка без переводов строк; адрес — ещё и
  один-единственный и без display-name: оба уезжают заголовками.
- Французские строки — только из `src/i18n/fr.ts`. Каркас владеет ветками
  `fr.mail.footer` и `fr.mail.senderName`, фичи добавляют свои в тот же объект.

## Куда уходят адреса получателей

Адрес получателя — единственные персональные данные, которые API передаёт
наружу. Список короткий и полный:

- **выход один** — правило выше: из сервиса в транспорт, второго пути не
  заводить;
- **в режиме отправки — Scaleway TEM, регион `fr-par`**: адреса обрабатываются в
  ЕС (RGPD). Регион — часть URL клиента, а не настройка окружения;
- **уходит только само письмо**: отправитель, один получатель, тема, обе версии
  тела, `project_id` и заголовки. Идентификаторов пользователя, коммуны и
  синистра провайдер не получает — не добавлять;
- **трекинга нет** ни click, ни open: ссылки никто не переписывает;
- **локально письма никуда не уходят** — локальный транспорт пишет их в
  `.mail-outbox` (см. «Транспорт»), и адреса в тех файлах настоящие.

Домен отправителя (`MAIL_SENDER_DOMAIN`) верифицирован у провайдера. Попадание
во «Входящие» автотестом не подтверждается — проверка ручная, её результат
фиксируется здесь.

**Проверка доставки 03.08.2026.** Отправитель `no-reply@mon-sinistre.fr`, письмо
собрано каркасом и отправлено `MailService` → `ScalewayMailTransport` — тем же
путём, которым пойдут письма продукта:

- `gmail.com` и `outlook.com` — «Входящие», не спам, с первой попытки.
  Корпоративный тенант Microsoft 365 показателем не считается: его фильтры
  настраивает администратор компании;
- SPF, DKIM (`d=mon-sinistre.fr`), DMARC — `pass`, доставка по TLS 1.3.
  Политика DMARC — `p=none` (`sp=none`), осознанно; условие перехода к
  `p=quarantine` — `docs/research/emails.md`, «Ограничения и риски»;
- `List-Unsubscribe`/`List-Unsubscribe-Post` дошли, почтовый клиент показывает
  штатную кнопку отписки; оба заголовка входят в подпись DKIM.

Проверка привязана к связке «домен + Scaleway TEM + этот каркас письма»: смена
любого из трёх — повод провести её заново, а не сослаться на эту запись.
Доставляемость ломается молча: письмо уходит с успехом провайдера и ложится в
спам.

## Транспорт

**За токеном `MAIL_TRANSPORT`**, не ветвлением по окружению: выбор живёт в одном
`useFactory` модуля, тесты подставляют свой транспорт через `overrideProvider`,
не трогая `process.env`.

Контракт транспорта: `send()` либо доставляет, либо бросает `MailDeliveryError` —
**без адреса получателя и тела письма в тексте и стеке**, потому что сервис
пишет их в лог (он же вычищает адрес, если транспорт правило нарушил).

**Локальный режим — умолчание** (`FileMailTransport`): свежий клон шлёт письма
в `.mail-outbox` без ключа и аккаунта. Единственное написание имени каталога —
`DEFAULT_MAIL_OUTBOX_DIR` здесь же, схема окружения его импортирует (вне кода их
два — `.gitignore` и `.env.example`, правятся вместе).

**Провайдер — `ScalewayMailTransport`**: HTTP API через нативный `fetch`,
fetch-функция — в конструкторе (тесты мокают HTTP без nock/msw). Инварианты
транспорта — от региона в URL до запрета редиректов — задокументированы
комментариями в самом файле, у кода, который без них выглядел бы ошибкой.

Всё, кроме `SENDING_TRANSPORT` (константа `mail-transport-name.ts`), — локальный
транспорт; незаданная переменная тоже. При `NODE_ENV=production` локальный
транспорт отвергается на старте.
